# WeGame Agent Demo

> 融入游戏平台的全旅程 AI 游戏助手概念 Demo：帮玩家选游戏、陪玩家打游戏，也帮玩家找到合适的游戏搭子。

[在线体验 WeGame Agent Demo](https://ww5667.github.io/wegame_agent/)

> 本项目是产品概念验证与交互原型，并非腾讯或 WeGame 官方产品。界面中的游戏、角色、帖子和玩家资料均为虚构内容。

## 产品定位

WeGame Agent 将分散在游戏前、游戏中和社区里的需求串成一条连续旅程。Agent 共享玩家的时间、偏好、对局状态和社交需求，并在合适的场景给出尽量简短、可解释的帮助。

```text
空闲时间 / 游戏偏好 / 好友状态 / 实时对局 / 组队需求
                         │
                         ↓
                   WeGame Agent
                         │
             ┌───────────┼───────────┐
             ↓           ↓           ↓
          推荐游戏     对局辅助     匹配搭子
        先理解再推荐   攻略与技巧   社区与组队
```

## 核心体验

### 1. AI 推荐游戏

- 玩家可以直接告诉 Agent 今晚有多少时间、想要什么节奏、是否想和朋友一起玩。
- Agent 根据需求返回解释清晰的首选游戏和三个备选项。
- 支持“只有 40 分钟”“想轻松一点”“想和朋友玩”等快捷条件。

### 2. 实时对局助手

- 点击首页的“开始游戏”可以进入模拟对局。
- 使用 `Ctrl + Space` 随时展开或收起游戏助手，`Esc` 可快速关闭。
- Agent 根据当前比分、经济差、资源时间和最近事件给出一条关键建议。
- 对局中央使用原创竞技场画面作为战术底图，实时标记和资源提示叠加在画面上。
- 支持即时查询攻略、下一波打法和装备选择。

### 3. 社区与 AI 找搭子

- 社区提供推荐、关注和最新动态。
- 玩家可以发布游戏时刻或组队帖子。
- 向 AI 描述时间、沟通习惯和游戏节奏后，可获得匹配搭子及匹配理由。
- “找队友”拥有独立路由，可集中查看完整玩家档案、匹配依据和在线时间。
- 支持邀请玩家，也可以让 Agent 先生成组队帖子草稿。

## 推荐演示流程

1. 打开[在线 Demo](https://ww5667.github.io/wegame_agent/)。
2. 在首页右侧和 Agent 对话，补充本次游戏需求。
3. 点击“开始游戏”进入对局助手，尝试 `Ctrl + Space` 快捷键和攻略快捷提问。
4. 进入“社区”，体验发布动态、AI 匹配搭子、邀请和生成组队帖子。

## 视觉与素材

- 采用接近 WeGame 客户端的深色框架、橙色品牌强调和紧凑信息层级。
- “最近游玩”和“为你推荐”均使用独立游戏封面，而不是抽象色块占位。
- 所有游戏名称和视觉素材均为原创虚构内容，不使用竞品平台、发行商或商业游戏素材。
- 原创封面经过 WebP 压缩，兼顾清晰度与页面加载体积。

## 当前实现

- React 19 + TypeScript
- Vite 8
- Tailwind CSS
- Lucide 图标
- 本地确定性交互逻辑
- 桌面端与移动端响应式布局
- GitHub Actions + GitHub Pages 自动部署

当前版本使用本地模拟数据展示产品交互，尚未连接真实游戏事件、在线大模型、攻略知识库或社交账号。后续可以直接将页面中的本地回复处理器替换为真实 Agent API。

## 本地运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

根据终端输出打开本地地址。生产构建：

```bash
npm run build
```

## 当前边界

- 对局、游戏目录、帖子和队友资料均为演示数据。
- AI 对话、攻略回答和搭子匹配使用本地规则模拟，不代表在线模型输出。
- “开始游戏”“邀请”“发布”等操作只改变 Demo 内部状态，不会启动真实游戏或发送真实消息。
- 原创图片由生成式图像工具制作，仅用于本概念 Demo。
